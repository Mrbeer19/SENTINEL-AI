# รายงานแต่ละเฟส

เขียนรายงานเฟสเป็น `phase-0-obeto.md`, `phase-0-beer.md` และเฟสถัดไปตามรูปแบบนี้ แล้วส่งสรุปใน Discord

```text
Phase / ผู้รับผิดชอบ:
สถานะ: ผ่าน / ผ่านบางส่วน / ติดขัด
ตอนนี้ระบบทำอะไรได้:
ไฟล์หรือ commit ที่เปลี่ยน:
ทดสอบจริง: คำสั่ง + ผล + หลักฐาน
ยังไม่ได้ทดสอบ/ยังไม่ผ่าน:
สิ่งที่เพื่อนต้องใช้หรือทำต่อ:
คนต้องตรวจ: เปิดหน้าใด/ลองทำอะไร/ควรเห็นผลแบบไหน
เฟสถัดไป: เริ่มได้ / รออะไร
```

รายงานทดสอบจากแต่ละเครื่องต้องระบุสภาพแวดล้อมและข้อจำกัด ไม่คัดลอกตัวเลขจากเครื่องอื่นมาอ้างเป็นผลตนเอง
