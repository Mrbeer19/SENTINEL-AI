ถ้ามาจาก IP เดียว ผลกระทบมักจำกัด แต่ถ้าบริการมีเพดานการเชื่อมต่อ (เช่น sshd) ผู้ใช้จริงอาจต่อไม่ได้ชั่วคราว

1. ตรวจว่า IP ไม่ใช่เครื่องของทีมหรือระบบภายในก่อน เคยเกิดกรณีระบบนับการเชื่อมต่อภายในของตัวเองแล้วเสนอบล็อก IP ของเครื่องเอง ปัจจุบันระบบตัด IP ของเครื่องและเครือข่าย Docker ออกแล้ว
2. อนุมัติบล็อกที่เว็บถ้าเป็นภายนอก และรู้ว่าการเชื่อมต่อพอร์ตอื่นยังไม่ถูกบล็อก
3. ข้อจำกัดที่รู้อยู่: prompt ของโมเดลไม่มีขั้นตัดสินชนิดนี้ ผลวิเคราะห์ของโมเดลอาจระบุเป็นชนิดอื่น แต่มาตรการที่เสนอยังถูกต้อง
