404 ตั้งแต่ 10 ครั้งจาก IP เดียวไม่จำเป็นต้องเป็นการสแกน ตัวอย่างที่พบได้
- หน้าเว็บอ้างถึงรูปหรือไฟล์ที่ถูกลบ เบราว์เซอร์ผู้ใช้จึงได้ 404 หลายครั้งต่อการเปิดหน้าเดียว
- bot ของเครื่องมือค้นหาไล่ URL เก่า
- ผู้ใช้หลายคนอยู่หลัง IP เดียวกัน (CGNAT ของเครือข่ายมือถือ)

ดูว่า path ใน incident เป็นชื่อไฟล์ของเว็บเองหรือเป็นรายชื่อแบบเครื่องมือสแกน ก่อนอนุมัติบล็อก
