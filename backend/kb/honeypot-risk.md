การขอ path กับดักเองยังไม่ทำให้เกิดความเสียหาย เพราะไฟล์ไม่มีอยู่จริง แต่เป็นสัญญาณที่แน่นอนสูงว่า IP นั้นกำลังสำรวจหาจุดอ่อน และมักตามด้วยการสแกน path อื่นหรือการลองช่องโหว่

ความเสี่ยงจริงอยู่ที่ว่าเว็บมีไฟล์แบบเดียวกันที่ไม่ใช่กับดักหลงอยู่หรือไม่ ถ้ามี ไฟล์สำรองฐานข้อมูลหรือ credential อาจหลุดได้ในคำขอเดียว

ข้อควรระวัง: เว็บอื่นสามารถฝังรูปที่ชี้มาที่ path กับดักเพื่อให้เบราว์เซอร์ของผู้ใช้ปกติขอแทน SENTINEL จึงไม่นับคำขอที่เบราว์เซอร์ระบุว่า `Sec-Fetch-Site: cross-site` หรือ `same-site`
