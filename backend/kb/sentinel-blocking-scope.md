- การบล็อกทุกชนิดบังคับใช้ที่ Caddy: IP ที่ถูกบล็อกได้ 403 จากทุกเว็บบนเครื่อง ระบบไม่แก้ firewall ของเครื่อง เพราะเครื่องใช้ร่วมกับผู้อื่น SSH และพอร์ตอื่นจึงตรวจจับได้แต่ไม่บล็อก
- การบล็อกที่ผู้ดูแลอนุมัติคงอยู่จนผู้ดูแลปลดที่หน้า Protection
- การบล็อกอัตโนมัติ (honeypot, path ของเครื่องมือสแกน, HTTP flood ระดับ CRITICAL) อยู่ 600 วินาที ไม่เกิน 10 IP ต่อชั่วโมง และมีแจ้งเตือนค้างจนผู้ดูแลรับทราบ
- ระบบไม่บล็อก IP ที่ป้องกันไว้ (IP ของเครื่อง เครือข่าย Docker และ Caddy) และบล็อกได้เฉพาะ IP ต้นทางของ incident
