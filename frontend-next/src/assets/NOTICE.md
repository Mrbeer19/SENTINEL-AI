# Land geometry

`land-110m.json` contains rounded exterior land rings from Natural Earth 1:110m land polygons, used only to draw the globe background. It contains no IP locations or security telemetry.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson

Natural Earth data is in the public domain: https://www.naturalearthdata.com/about/terms-of-use/
