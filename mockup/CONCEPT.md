# SENTINEL AI — แนวคิดหน้าตาและประสบการณ์ใช้งาน

SENTINEL AI ควรให้ความรู้สึกเหมือนห้องควบคุมความปลอดภัยที่ผู้ดูแลใช้ทำงานจริง หน้าจอพื้นสีกรมท่าเข้มช่วยให้ข้อมูลจำนวนมากอ่านได้ต่อเนื่อง สีฟ้าอมเขียวสื่อถึงระบบที่ทำงานปกติ สีแดงชี้ภัยคุกคาม สีส้มบอกสิ่งที่รอการตัดสินใจ และสีเขียวยืนยันผลที่ตรวจสอบแล้ว ทุกสีต้องมีข้อความสถานะกำกับ ไม่ใช้สีเป็นหลักฐานเพียงอย่างเดียว

เมื่อเปิดระบบ ผู้ดูแลเห็น **Dashboard** ก่อน: จำนวน events, ภัยคุกคามที่ยังเปิดอยู่, alerts สำคัญ และ IP ที่ถูกบล็อก ใต้ตัวเลขเป็นกราฟ traffic และตาราง incident ล่าสุด ด้านขวาเป็นปุ่มจำลองเหตุการณ์, สถานะของ Agent Workflow และ live events จึงเห็นทั้งภาพรวมและเรื่องเร่งด่วนในจอเดียว

เมื่อเกิด SSH brute force ผู้ดูแลเปิด **Incident** เพื่อดูต้นทาง เวลา จำนวน failed logins และหลักฐาน จากนั้นหน้า **AI Agent** แสดงลำดับงานจริงทีละขั้น: detection, tool calls, analysis, defense proposal, policy validation, approval, execution และ verification แต่ละขั้นควรเปิดดู input/output และเวลาที่ใช้ได้ เพื่อพิสูจน์ว่า Agent ทำงานจริง ไม่ใช่แค่ข้อความสรุป

ข้อเสนอป้องกันต้องแสดง action, IP เป้าหมาย, ระยะเวลา และผล policy check อย่างชัดเจน ผู้ดูแลกดอนุมัติหรือปฏิเสธได้ หลังอนุมัติ หน้า **Firewall Simulator** แสดง rule ที่เพิ่มและภาพเปรียบเทียบ packet ก่อนกับหลังป้องกัน หากทดสอบ packet จาก IP นั้นแล้วถูก deny จึงแสดงว่า verification ผ่าน

หน้า **Reports** รวมหลักฐาน การวิเคราะห์ การอนุมัติ และผลการทดสอบเป็น timeline ที่ตรวจย้อนหลังได้ นี่คือส่วนสำคัญสำหรับการสอบ เพราะช่วยแสดงว่าโครงการเป็นระบบวิศวกรรมที่มีข้อมูลตั้งแต่ต้นทางถึงผลลัพธ์ ไม่ใช่เพียง dashboard ที่สวย

## สิ่งที่ม็อกอัพนี้สาธิต

- เปิดดู 6 หน้า: Dashboard, Incidents, AI Agent, Firewall, Simulator และ Reports
- กดเริ่มสถานการณ์ SSH Brute Force เพื่อเปลี่ยนข้อมูลตัวอย่าง
- กด Approve หรือ Reject แล้วเห็นผลต่างกันใน Firewall และ Reports
- กด Reset เพื่อกลับสู่สถานะเริ่มต้น
- รองรับจอคอมพิวเตอร์และโทรศัพท์

ไฟล์ `index.html` เป็น **ต้นแบบหน้าตาและการโต้ตอบด้วย mock data** ยังไม่เชื่อม FastAPI, Ollama, SQLite หรือ Firewall Simulator จริง เมื่อพัฒนาระบบจริงควรแทน state ใน JavaScript ด้วย API/WebSocket ตาม contract ที่ทีมตกลงกัน
