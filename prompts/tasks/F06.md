# SENTINEL AI task F06: Deploy เว็บจริงและทดสอบผ่าน HTTPS
Pipeline: frontend | Phase: 4
Dependencies: F04
Deliverable: docs/deployment.md, production config, URL ที่เปิดใช้จริง และผล smoke test
Acceptance: มี URL HTTPS; API/WSS จริงผ่าน; login จำกัดสิทธิ์; Docker/volume/Ollama ผ่าน; ไม่มี secret ในเว็บ; มี rollback และผลเทสจาก URLจริง

อ่าน docs/deployment-plan.md เตรียม deploy React/Vite โดยแนะนำ Vercel Hobby สำหรับโปรเจกต์ส่วนตัวนี้ ใช้ frontend เป็น root directory, npm run build และ dist ออกแบบ API origin/WebSocket URL สำหรับ production โดยไม่ hardcode localhost หรือฝัง admin key ใน VITE_* ประสาน Obeto เรื่อง CORS, login/access control และ backend ที่เชื่อม Qwen บนเครื่อง RTX 4060 ผ่าน protected tunnel ตรวจว่า frontend URL ไม่ได้เปิดแค่ mock และ API/WSS ใช้งานจากอุปกรณ์อื่นได้จริง ไม่เปิด backend ปัจจุบันออก internet ก่อนมี access control ครอบคลุม HTTP/WS ทดสอบ HTTPS, authenticated API/WSS, reload/reconnect, responsive, Ollama/backend offline และ flow หลักจาก URL deploy บันทึกวิธีตั้งค่า environment, URLจริง, deployment version, smoke-test evidence และ rollback ใน docs/deployment.md หากยังไม่มีบัญชี/สิทธิ์ hosting/domain ให้เตรียม config และรายงานสิ่งที่ต้องรอ ห้ามอ้างว่า deploy แล้วถ้ายังไม่มี URL ที่ตรวจผ่าน ห้ามสมัครบริการเสียเงินหรืออัปเกรดแผนโดยไม่ได้รับอนุญาต เพิ่ม Dockerfile/Compose ร่วมกับ Obeto สำหรับ FastAPI และ SQLite persistent volume ใน Docker Desktop โดยเชื่อม Ollama บน Windows host ผ่าน host.docker.internal ทดสอบ build/start/stop/recreate, healthcheck, database persistence และ GPU model connection จริง เขียนลำดับเปิด Docker/Ollama/tunnel และข้อจำกัดเมื่อเครื่องปิด

ทำงานในโฟลเดอร์โปรเจกต์ที่รัน CLI เท่านั้น ตรวจไฟล์ที่มีอยู่ก่อนแก้ไข รักษา API contract ของทีม
เมื่อเสร็จ สรุปไฟล์ที่แก้ วิธีทดสอบ ผลทดสอบ และข้อจำกัดที่เหลือ
AI ต้องรันทดสอบจริงและเขียนรายงานพร้อมหลักฐาน ผู้สั่ง AI อ่านภาพรวมและตรวจผลก่อนให้ทีมใช้ต่อ ไม่ต้องใช้คำสั่งบอตส่งงาน
