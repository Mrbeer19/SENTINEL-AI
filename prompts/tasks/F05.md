# SENTINEL AI task F05: UI polish และสไลด์หลักฐานการทำงาน
Pipeline: frontend | Phase: 4
Dependencies: F04
Deliverable: หน้า UI พร้อมสอบและภาพประกอบ
Acceptance: จอ projector อ่านได้, responsive, status ชัด, screenshot แสดงจริงไม่ใช่ mock

ตรวจและเก็บงาน UI ของ SENTINEL AI สำหรับพรีเซ็น: hierarchy, contrast, projector readability, responsive, empty/error/waiting states จับภาพหน้าจอจาก backend จริงของ flow เดโม จัดสรุปหน้าที่แต่ละหน้ากับภาพสำหรับสไลด์ ไม่เพิ่ม feature P2

ทำงานในโฟลเดอร์โปรเจกต์ที่รัน CLI เท่านั้น ตรวจไฟล์ที่มีอยู่ก่อนแก้ไข รักษา API contract ของทีม
เมื่อเสร็จ สรุปไฟล์ที่แก้ วิธีทดสอบ ผลทดสอบ และข้อจำกัดที่เหลือ
AI ต้องรันทดสอบจริงและเขียนรายงานพร้อมหลักฐาน ผู้สั่ง AI อ่านภาพรวมและตรวจผลก่อนให้ทีมใช้ต่อ ไม่ต้องใช้คำสั่งบอตส่งงาน
