# Dashboard graphics

- `sentinel-orbit-logo.svg`, `sentinel-orbit-logo-light.svg`: SENTINEL AI logo for dark and light themes, drawn as SVG for this project. `sentinel-orbit-mark.svg` is the favicon from the same shape.
- `sentinel-pilot.png`, `sentinel-investigator.png`, `sentinel-welcome.png`, `sentinel-laptop.png`: the SENTINEL mascot in four poses (Overview, investigation pages, sign-in and approval pages, sidebar on other pages).
- `sentinel-icon-atlas.png`: menu and section icons in the mascot's style, one 4 × 4 sheet read by `Icon` in `src/ui.jsx`.
- `network-grid.svg`: local vector grid, registration marks and accent pixels used behind the globe.
- `sentinel-node.svg`: local isometric application node illustration used in the protection panel.
- `nex.svg`: earlier mascot drawn as plain SVG shapes.

These graphics are decorative. They do not represent measured traffic, IP locations or threat findings. The globe uses the Natural Earth geometry documented in `src/assets/NOTICE.md`.
