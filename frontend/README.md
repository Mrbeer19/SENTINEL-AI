# SENTINEL AI — M5 SOC

Frontend นี้เป็นหน้าผู้ดูแลของ M5 ส่วน Neo ใช้ Terminal ตาม `../scripts/neo/README.md` ไม่มีลิงก์ไปหน้าควบคุม Neo ในเมนู SOC และ production build มี entry ของ M5 เท่านั้น

## เปิดใช้งานระหว่างพัฒนา

รัน backend ที่ `127.0.0.1:8000` และรัน `npm run dev` ในโฟลเดอร์นี้ เปิด URL ที่แสดงจาก Vite โดย API และ WebSocket จะผ่าน proxy ไป backend

`npm run build` สร้าง `dist/` สำหรับ backend เสิร์ฟหน้าเว็บ ในเดโมสองเครื่องให้ Neo เรียก LAN IP ของ M5 ที่ port backend โดยตรง เพื่อให้ backend เห็น IP ต้นทาง Neo จริง

## หน้าจอ

Overview, Incidents, Incident Detail, Agent Trace, Approvals, Rules, Reports และ Demo Lab ใช้ React components และรูปแบบร่วมกัน รองรับจอกว้างและหน้าจอแคบ ตารางเลื่อนในกรอบเมื่อพื้นที่ไม่พอ

- `src/style.css`: stylesheet เดียวสำหรับ theme, components, ขนาดตัวอักษร, UX และ responsive ใช้ขนาดพอดีที่ซูม 100% และซูมเบราว์เซอร์เพิ่มเวลานำเสนอได้ แต่ละ breakpoint อยู่ในบล็อกเดียว เรียงจากจอกว้างลงไปจอแคบ
- `src/components/GlobeCanvas.jsx`: ลูกโลกหมุนจากรูปทรงแผ่นดินในเครื่อง ไม่มีการส่ง IP ไปบริการภายนอก
- `src/components/NetworkTopology.jsx`: ข้อมูลเครือข่ายและพรีวิวหมุด ระบุ DEMO เมื่อกำหนดพิกัดเพื่อแสดงตัวอย่าง
- `src/components/ActivityChart.jsx`: กราฟจากรายการ request ที่ backend ส่งกลับ ไม่สร้าง traffic สมมติ

## หมุดบนลูกโลก

Live network ใช้ข้อมูลจริงของระบบ ส่วน Neo · demo location ใช้ source IP ที่บันทึกไว้กับพิกัดเมืองสำหรับเดโม Sample external IP เป็นภาพตัวอย่างใช้ TEST-NET เท่านั้น โหมดเดโมไม่สร้าง incident, ไม่เรียกโมเดล และไม่เพิ่มกฎบล็อก

ยังไม่ได้เชื่อม GeoIP lookup สำหรับ Public IP การระบุเมืองบนลูกโลกในโหมดเดโมจึงไม่ใช่ตำแหน่งที่ค้นได้จาก IP จริง สถานะจาก rule fallback แสดงแยกจากผลโมเดล

ผลตรวจหน้าจอและ workflow อยู่ที่ `../reports/frontend-review-2026-10-19.md`

## ขั้นตอนการใช้งาน

- เปิด “เริ่มใช้งานอย่างไร” เพื่อดูภาพรวม M5 / Neo และลิงก์แต่ละขั้นตอน
- Overview และ Incident Detail มีแถบ “ขั้นตอนถัดไป” ตามข้อมูลล่าสุด: วิเคราะห์ → ตรวจข้อเสนอ → ส่งคำขอใหม่ยืนยันผล → รายงาน
- Approvals ต้องตรวจ IP / ระยะเวลา / ผู้ตรวจทาน แล้วกดยืนยันอีกครั้ง การเปิดกล่องตรวจทานหรือกดยกเลิกไม่ส่งคำตัดสินไป backend
- การอนุมัติยังไม่นับเป็นการบล็อกสำเร็จ ต้องมีคำขอใหม่ถูกปฏิเสธก่อน หากกฎหมดอายุหรือถูกปลด จะแสดงตามนั้น
- ตัวกรองบอกจำนวนผลลัพธ์ มีปุ่มล้าง และไม่ค้างรายละเอียดของรายการที่ถูกกรองออก แท็บประวัติแสดงเฉพาะรายการในประวัติ
- ระหว่างทำงานปุ่มจะป้องกันการส่งซ้ำ มีสถานะและผลการทำงานที่มุมล่าง ข้อผิดพลาดใช้คำอธิบายพร้อมส่วนรายละเอียดที่เปิดดูได้
- เมื่อเชื่อมต่อไม่ได้ จะแยก SAVED DATA / NO DATA จาก LIVE DATA เพื่อไม่ให้เข้าใจว่าข้อมูลเดิมยังสดอยู่
